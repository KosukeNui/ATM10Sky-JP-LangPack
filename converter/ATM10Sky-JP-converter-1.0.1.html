ATM10 To the Sky 日本語化 変換ツール

対応バージョン: パック 2.3.1　／　このページはパソコンの中だけで動きます（ファイルはどこにも送信しません）

このツールがすること

パックの中の次のファイルを読み、画面に出る英語の文だけを「翻訳キー＋元の英語」の形に書き換えたファイルを作ります。元の英語はそのまま残るので、日本語化リソースパックを入れていない人や英語の設定の人には、今までと同じ英語が表示されます。それ以外（スクリプトの動き・設定値など）は一切変えません。

1. パックのフォルダを選ぶ

インスタンスのフォルダ（kubejs と config が入っているフォルダ）を選んでください。ブラウザが「アップロード」と表示することがありますが、送信はされません。

2. 結果

まだ変換していません。

3. 置き換える

  1. 念のため、元のファイルをバックアップしてください。
  2. ダウンロードした zip を展開し、中の kubejs と config フォルダを、インスタンスのフォルダに上書きでコピーします。
  3. 展開しようとして「このファイルへのアクセスがブロックされています」と出たときは、zip を右クリック →「プロパティ」→ いちばん下の「許可する」にチェック → OK のあと、もう一度展開してください。または、結果の欄の「このファイルだけをダウンロード」でファイルを1つずつ保存し、表に書いてある場所（例: config/skyblockbuilder/）へ上書きでコピーしてください。
  4. マルチプレイでは、サーバーにも同じファイルを置いてください（config/skyblockbuilder と kubejs/data・kubejs/server_scripts はサーバーが読みます。kubejs/client_scripts は各プレイヤーのクライアントが読みます）。
  5. パックを更新したときは、更新後のファイルでこのツールをもう一度使ってください。
